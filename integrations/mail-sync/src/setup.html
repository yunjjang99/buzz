KOVAR BUZZ / 메일 연결

두 회사의 메일을 Buzz에서

받은메일과 보낸메일을 회사별 채널에 모읍니다. 최근 3개월부터 가져오며, 이후에는 약 2분 간격으로 새 메일을 확인합니다.

이 화면은 서버가 설치된 Mac에서만 열립니다. 아래 비밀번호는 일반 로그인 비밀번호가 아닌 앱 비밀번호입니다. 채팅에 보내지 말고 이 화면에 직접 입력하세요.

수집 상태를 확인하고 있습니다.

코바 업무 자동 분류

분류 상태 확인 중

견적요청·견적관리·공급처오퍼·주문발주·배송입고·운영관리·정보알림으로 분류합니다. 애매한 메일은 공동메일분류 채널에서 확인합니다. 분류는 메일의 업무 종류를 표시하며 판매나 결제를 확정하지 않습니다.

연결 전 준비

  1. Gmail: nova@kovar.kr로 Google에 로그인한 뒤 2단계 인증을 설정하고 앱 비밀번호를 생성해 코바 입력칸에 넣으세요. 조직에서 앱 비밀번호를 막았다면 관리자 설정 또는 별도 OAuth 연결이 필요합니다.
  2. 네이버: cbtcshin@naver.com의 메일 설정 → IMAP/SMTP에서 IMAP 사용을 켜고, 보안 설정의 2단계 인증에서 애플리케이션 비밀번호를 만들어 청북 입력칸에 넣으세요.

원본 메일을 보내거나 삭제하거나 읽음 처리하지 않습니다. 스팸·휴지통·임시보관함은 제외합니다. 첨부파일은 이름을 기록하며, 8 MiB 초과 메일은 제목·주소 등 기본 정보만 기록합니다. 자동 회신·전달 메일은 견적 발송이나 판매 확정으로 처리하지 않습니다.

Buzz 직원은 공개된 회사별 메일연동 채널에 참여할 수 있습니다. Mac과 Docker가 실행 중이어야 수집이 이어집니다.
